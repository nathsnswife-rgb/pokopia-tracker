# Pokopia Companion

An Android companion application for Pokopia that helps players manage and track their Pokémon collection, habitats, friendships, and overall game progress.

## Features

- Track caught Pokémon
- View habitat information
- View friendship preferences
- Track collection progress
- Search Pokémon quickly
- Simple offline interface
## Built With

- Android Studio
- Java
- Gradle
